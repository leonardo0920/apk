M MaraTour

App para conductores

Maneja con MaraTour.

MaraTour es una empresa de taxis de Maracaibo, Zulia. Esta aplicación es para nuestros conductores: les permite conectarse con la empresa y atender los servicios de forma simple y organizada, directamente desde su teléfono.

Descargar para Android

Archivo APK · 55 MB

Cómo instalar

  1. Descarga el archivo desde tu teléfono Android.
  2. Ábrelo desde las descargas o la barra de notificaciones.
  3. Si Android lo pide, permite instalar apps desde esta fuente.
  4. Toca Instalar y abre MaraTour.

Importante

  • Solo para conductores de MaraTour.
  • Disponible únicamente para Android.
